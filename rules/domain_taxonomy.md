# 领域分类体系 (Domain Taxonomy)

版本 `1.0` · 对应 `knowledge_item.schema.json` 1.0.0

> 领域是受控枚举，写死在 schema 里；标签是自由的，随时长出来。
> 改动领域代码属于破坏性变更，需要版本升级、映射表和迁移脚本。

---

## 1. 领域回答什么

`domain` 回答 **这条知识在讨论什么**；`content_type` 回答 **这条知识是什么性质**。
两者正交。领域可以多选（1–3 个），但领域不是标签。

## 2. 十一个领域

| 代码 | 名称 | 覆盖范围 | 不包含 |
|---|---|---|---|
| D01 | 个人认知与价值观 | 自我认识、价值判断、人生选择、情绪与信念、行动原则 | 学科知识；人际策略的具体操作（→ D11） |
| D02 | **哲学、宗教与思想** | 哲学概念、伦理、宗教理论、思想史、认识论、意识形态 | 历史事件（→ D10）；社会实证（→ D11） |
| D03 | 商业与管理 | 企业运作、组织、战略、营销、财务、会计实务 | 宏观产业与贸易（→ D04） |
| D04 | 产业研究与国际贸易 | 产业结构、供应链、贸易政策、区域经济、地缘经济 | 单个企业内部管理（→ D03） |
| D05 | 语言与表达 | 外语学习、写作、演讲、翻译、修辞、沟通技巧 | 语言学理论（→ D02） |
| D06 | 职业发展与能力建设 | 职业路径、技能养成、求职、学习方法、协作能力 | 具体项目交付（→ D07） |
| D07 | 项目与产品 | 产品设计、需求、项目推进、工具链、系统搭建 | AI 工具与方法（→ D09）；通用管理（→ D03） |
| D08 | 生活与审美 | 健康、生活方式、艺术、文学、设计、饮食、旅行 | 创作产出本身（不入知识层）；AI 内容生产（→ D09） |
| **D09** | **AI、知识管理与生产系统** | AI 工具与模型应用、Agent 工作流、自动化、个人知识管理、记忆系统、知识库、学习生产系统、人机协作 | 一般软件产品设计（→ D07）；AI 的哲学讨论（→ D02） |
| **D10** | **历史、文化与制度** | 历史事件与人物、文化传统、制度演变、跨文化比较、建筑与物质文化史 | 哲学思想（→ D02）；当代公共政策（→ D11） |
| **D11** | **社会科学与公共议题** | 社会学、政治学、公共政策、群体行为、社会规范、教育与社会结构 | 经济史（→ D10）；企业行为（→ D03） |

### D09 的边界（最容易误用）

| 属于 D09 | 不属于 D09 |
|---|---|
| 用 Agent 做知识抽取的流程设计 | 某个 Agent 产品的商业分析（→ D03） |
| 个人知识库的结构与 Schema | 用 AI 写的文章本身（→ D08 或不入库） |
| 提示词工程方法 | 提示词的哲学意涵（→ D02） |
| 自动化工作流的搭建 | 工作流服务的公司战略（→ D03） |

判定口诀：**讲"怎么用 AI/怎么管知识"，是 D09；讲"AI 是什么/意味着什么"，是 D02。**

### D02 / D10 / D11 的边界

| 问题 | 归属 |
|---|---|
| 李约瑟难题的成因解释 | D10（历史）＋ D02（方法论），主领域取问题重心 |
| 康德的义务论 | D02 |
| 科举制如何演变为选官制度 | D10 |
| 当代社会信任度下降的原因 | D11 |
| 教育公平政策评估 | D11 |

## 3. v1 → v2 映射

| v1 | v2 | 处理 |
|---|---|---|
| D01 | D01 | 不变 |
| **D02 人文与社会科学** | **D02 / D10 / D11** | **按内容拆分**，无法判定者保留 D02 并标记待审 |
| D03–D08 | D03–D08 | 不变 |
| 无 | **D09** | 新增；由全库扫描迁移 |
| 无 | **D10** | 新增，承接原 D02 的历史文化部分 |
| 无 | **D11** | 新增，承接原 D02 的社科公共部分 |

---

## 4. 归属判定规则

1. 看问题意识，不看材料来源。
2. 看主要受众与复用场景。
3. 两可时选方法论所在领域。
4. 多领域时主领域排第一，最多 3 个。
5. 仍无法判断 → 保留上位领域 + `review_status = needs_review`，附 `domain_candidate` 供人工定夺。

## 5. 扩展与版本

| 变更 | 版本位 | 迁移 |
|---|---|---|
| 新增领域 | minor | 否 |
| 拆分/合并/重定义 | **major** | 是，需映射表 + 脚本 + 差异报告 |
| 仅改描述 | patch | 否 |

**当前上限 11 个。** 超过说明维度用错，应改用标签。

## 6. 与标签的分工

能穷举的是领域（11 个，受控），会长出来的是标签（自由，≤12 个/条）。
「李约瑟难题」是标签，「D10 历史、文化与制度」是领域。
